# Security

## Reporting vulnerabilities

Please **do not** open a public GitHub issue for undisclosed security problems.

Email or DM the maintainers (use contact info on the GitHub org or profile if available), or open a **private security advisory** via GitHub **Security → Advisories** if enabled on this repository.

## Credentials

- Never commit `.env` files or API keys.
- WattTime credentials are **per-user**; do not embed shared production keys in client-side or public artifacts.
